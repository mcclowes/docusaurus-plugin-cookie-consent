# Roadmap

The previous improvement ledger mixed completed work with stale suggestions. Completed changes now belong in [CHANGELOG.md](CHANGELOG.md).

Potential future work:

- Add a category-selection form so users can save a mixed set of optional preferences directly in the banner.
- Restore focus to the element that opened the preference dialog.
- Add live-region announcements for consent changes.
- Add first-class localization for category labels and the details toggle.

Open an issue before starting a larger change so its API and compatibility requirements can be agreed first.
